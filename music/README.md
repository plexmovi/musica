# Mi Reproductor MP3

Reproductor MP3 sencillo hecho solamente con HTML, CSS y JavaScript.

## Uso local
Abre `index.html` en tu navegador y selecciona uno o varios archivos MP3.

## Publicarlo en GitHub Pages
1. Crea un repositorio en GitHub.
2. Sube `index.html`.
3. Ve a **Settings → Pages**.
4. Selecciona la rama `main` y la carpeta `/root`.
5. Guarda y espera a que GitHub publique la página.

Los MP3 seleccionados mediante el botón se reproducen localmente en el navegador.

### Biblioteca MP3 fija
Si quieres que la página tenga canciones incorporadas, puedes crear una carpeta `music/` y enlazar archivos desde JavaScript/HTML. Ten en cuenta que los archivos de audio estarán disponibles públicamente en el sitio.
